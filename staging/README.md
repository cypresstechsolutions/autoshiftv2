# Staging Directory

Working area for manifests and policies in progress. Drop files here for integration into the main repo structure.

## Workflow
1. Create a subdirectory for your work (e.g. `staging/policy-name/`)
2. Add manifests and a brief README with integration instructions
3. Push to the fork
4. Once integrated into the proper repo location, clean up from staging

## Convention
- One subdirectory per policy/feature
- Include a README or notes file with context and instructions
- Staging content is temporary — remove after integration
